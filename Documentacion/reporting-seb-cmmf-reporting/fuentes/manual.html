Reporting SEB

Manual de usuario · CMMF Code (Reporting) y familias · Extensión Zummo 1.0.0.1023 · octubre 2026

Para qué sirve

La pantalla Reporting SEB resume las ventas facturadas de cada mes agrupadas como las pide SEB: por Mes, Business Unit, MLA y CMMF Code. Para cada grupo da la cantidad, el importe y el coste, y permite ver el detalle de los movimientos que lo forman.

Qué cambia en esta versión

  • El reporting agrupa por el campo CMMF Code (Reporting) del producto, y no por el CMMF Code anterior. El CMMF Code sigue existiendo, pero se usa para la asignación por numerador, no para el reporting.
  • Cada Familia puede tener su propio CMMF Code (Reporting). Si un producto no tiene el suyo, la carga del reporting usa el de su familia.
  • Hay una acción nueva en la lista de familias que rellena el CMMF Code (Reporting) de los productos que lo tienen vacío con el de su familia.
  • Otras pantallas también muestran ya el CMMF Code (Reporting): los movimientos de producto y la lista de productos PI2. La importación de productos desde Excel de SEB también lo rellena.

CMMF Code (Reporting): producto y familia

Qué código se usa

Situación del productoCMMF Code en el reporting
Tiene CMMF Code (Reporting)El del producto. Manda siempre sobre el de la familia.
No lo tiene, y su familia síEl de la familia. El producto no se modifica: el código solo se usa en el reporting.
No lo tiene, ni su familiaQueda en blanco. Sus ventas se agrupan en una línea con CMMF Code vacío.
Esta regla se aplica cuando se pulsa Cargar. Si se cambia el código de un producto o de una familia, los meses ya cargados no cambian hasta que se vuelven a cargar.

Informar el CMMF Code (Reporting) de la familia

  1. En la ficha de un producto, ir al grupo Clasificación.
  2. En el campo Familia, abrir el desplegable y pulsar Seleccionar de la lista completa.
  3. Se abre la lista de valores de las familias. Rellenar la columna CMMF Code (Reporting) en cada familia.

Los códigos de la maqueta son solo un ejemplo. La columna CMMF Code (Reporting) y la acción del apartado siguiente solo aparecen cuando la lista está filtrada por Familia. Por eso es mejor entrar desde el campo Familia del producto.

Copiar el código de la familia a los productos

No es obligatorio para el reporting, porque la carga ya usa el código de la familia. Sirve para dejar el código guardado en el producto, por ejemplo para verlo en la ficha, en los movimientos o en otros informes.

  1. En la lista de valores de las familias, seleccionar una o varias familias.
  2. Pulsar la acción Actualizar CMMF Code (Reporting) productos.
  3. Confirmar: "¿Desea actualizar el CMMF Code (Reporting) de los productos sin informar de 3 familias seleccionadas?".
SituaciónQué pasa
Producto sin CMMF Code (Reporting)Recibe el CMMF Code (Reporting) de su familia.
Producto que ya tiene CMMF Code (Reporting)Se salta. Nunca se sobrescribe un código.
Producto bloqueadoSe actualiza también, porque puede tener ventas de meses anteriores que salen en el reporting.
Familia sin CMMF Code (Reporting)Se salta la familia entera.

Cargar y consultar el reporting

Cargar los datos

Buscar Reporting SEB.

  1. En Filtro Fecha, escribir el periodo. Por ejemplo, 01/09/26..30/09/26 para septiembre.
  2. Pulsar Cargar y confirmar: "¿Desea Cargar los datos de filtro …?".
ReglaDetalle
Siempre meses completosEl filtro se amplía al mes entero. Con 15/09/26..10/10/26 se cargan septiembre y octubre completos.
Recalcula, no sumaAntes de cargar se borran los datos de los meses del filtro y se vuelven a calcular. Se puede cargar un mes las veces que haga falta.
El resto no se tocaLos meses que están fuera del filtro se conservan tal cual.
Qué ventas entranLos movimientos de valor de venta con cantidad facturada y fecha de registro dentro de los meses del filtro.
Filtro incompletoSi falta la fecha inicial o la final, da el error "Indique un filtro de fecha con fecha inicial y final.".
El Filtro Fecha solo se usa para la acción Cargar: no filtra las líneas de la pantalla. Para ver un mes, filtrar la columna Mes o usar el panel de filtros.

Consultar y ver el detalle

Cada línea es un grupo Mes + Business Unit + MLA + CMMF Code, con sus totales y las columnas Fl1 y Fl2.

Al pulsar sobre Quantity, Amount o Costs se abre Reporting SEB Details, con los movimientos que forman esa línea: fecha, nº documento, producto y descripción, familia y clasificación de ventas, cliente y su CIF, y los mismos códigos SEB.

En el detalle, la columna Familia ayuda a ver de qué familia viene un CMMF Code que no está en el producto.

Puesta en marcha

Pasos para dejarlo funcionando después de instalar la versión:

  1. Copia de los códigos anteriores (la hace Sistemas una sola vez): el CMMF Code de los productos se copia a CMMF Code (Reporting) cuando este está vacío.
  2. Informar el CMMF Code (Reporting) en las familias.
  3. Opcional: lanzar Actualizar CMMF Code (Reporting) productos en las familias.
  4. Volver a Cargar en Reporting SEB los meses que ya estaban cargados, para que se agrupen con el código nuevo.
