Asignación de CMMF Code

Manual de usuario · Configuración y asignación · Extensión Zummo 1.0.0.1021 · octubre 2026

Para qué sirve

Los productos que se reportan a SEB llevan dos campos: CMMF Type y CMMF Code. Hasta ahora los dos se escribían a mano.

Ahora:

  • el CMMF Type se elige de una lista de valores, que se mantiene en Textos Auxiliares;
  • cada CMMF Type tiene su propio numerador (nº de serie);
  • el CMMF Code se genera automáticamente con el numerador de su tipo, desde la ficha del producto o desde la lista, para varios productos a la vez.

Funciona igual que la asignación de códigos GTIN (EAN13) que ya existía.

1. NumeradorCrear un nº de serie para cada tipo.
→
2. CMMF TypeDar de alta el tipo y ponerle su numerador.
→
3. ProductoInformar el CMMF Type del producto.
→
4. AsignarGenerar el CMMF Code desde la ficha o la lista.

Los pasos 1 y 2 son de configuración y se hacen una sola vez por tipo. Los pasos 3 y 4 son el trabajo diario de alta de productos.

Configuración

Paso 1. Crear el numerador

Buscar Nos. serie y crear una serie nueva para cada CMMF Type. Por ejemplo:

CódigoDescripciónNº inicialNº final
CMMF-ACMMF Code tipo AA000001A999999
CMMF-BCMMF Code tipo BB000001B999999
  • Marcar Nos. predeterminados en la serie.
  • El CMMF Code admite hasta 20 caracteres.
  • El código que se asigna es el siguiente número de la serie. Si un producto ya tiene un CMMF Code de antes, conviene empezar la serie después del último que se haya usado, para no repetir códigos.
Los valores de la tabla son solo un ejemplo. El formato de los códigos lo marca SEB.

Paso 2. Dar de alta los CMMF Type

La forma más sencilla es entrar desde la ficha de un producto:

  1. En la ficha, ir al grupo Códigos SEB.
  2. En el campo CMMF Type, abrir el desplegable y pulsar Seleccionar de la lista completa.
  3. Se abre la lista de valores ya filtrada para los CMMF Type. Crear una línea por tipo:
Valores · CMMF Type
NºDescripcion · Nº Serie CMMF
ATipo A · CMMF-A
BTipo B · CMMF-B
CampoQué poner
NºEl código del tipo. Solo 1 carácter (A, B, 1…), porque es lo que admite el campo CMMF Type del producto.
DescripcionTexto que explica el tipo. Se ve en el desplegable al elegirlo.
Nº Serie CMMFEl numerador creado en el paso 1. Sin él, ese tipo no genera códigos.
Varios CMMF Type con el mismo numerador: se puede poner el mismo Nº Serie CMMF en dos o más tipos. En ese caso comparten la numeración: los códigos salen correlativos de la misma serie sea cual sea el tipo del producto, y nunca se repiten entre ellos. Por ejemplo, si los tipos A y B usan CMMF-A, un producto de tipo A puede recibir A000001 y el siguiente, de tipo B, A000002. Si cada tipo debe tener sus propios códigos, hay que crear un numerador para cada uno.
Importante: hay que dar de alta todos los CMMF Type que ya tienen los productos. Si un producto tiene un tipo que no existe en la lista, BC dará error al volver a editar el campo en la ficha.
La columna Nº Serie CMMF solo aparece cuando la lista está filtrada por CMMF Type. Por eso es mejor entrar desde el campo del producto y no buscando "Valores" directamente.

Asignación de códigos

Paso 3. Informar el CMMF Type del producto

En la ficha del producto, grupo Códigos SEB, elegir el CMMF Type en el desplegable. Solo se pueden elegir los tipos dados de alta en el paso 2.

En la lista de productos, la columna CMMF Type viene oculta. Para verla, usar Elegir columnas, y lo mismo con CMMF Code.

Paso 4a. Asignar desde la ficha (un producto)

En la ficha, pulsar el botón … del campo CMMF Code:

SituaciónQué pasa
Sin CMMF Code y con CMMF TypePide confirmación: "¿Desea asignar un nuevo CMMF Code a 260525 …?". Al aceptar, asigna el siguiente número del numerador de su tipo.
Ya tiene CMMF CodeAvisa: "El producto … ya tiene CMMF Code …". No lo cambia.
Sin CMMF TypeDa error: hay que informar primero el CMMF Type.
Tipo sin numeradorNo asigna nada. El resumen indica CMMF Type sin numerador: 1. Hay que completar el paso 2.

Paso 4b. Asignar desde la lista (varios productos)

  1. En la lista de productos, seleccionar los productos. Se pueden filtrar antes, por ejemplo por CMMF Code vacío.
  2. Pulsar la acción Asignar CMMF Code, que está junto a Asignar GTIN.
  3. Confirmar: "¿Desea asignar CMMF Code a 25 productos seleccionados?".

Para cada producto seleccionado:

SituaciónQué pasa
Sin CMMF Code y con CMMF TypeAsigna el siguiente número del numerador de su tipo.
Ya tiene CMMF CodeLo salta. Nunca se sobrescribe un código.
Tipo sin numeradorLo salta.
Sin CMMF TypeDa error y no se asigna ningún código a ninguno de los seleccionados. Hay que informar el tipo y repetir.

Al terminar aparece un resumen:

Resumen
CMMF Code asignados: 22
Ya tenían CMMF Code: 2
CMMF Type sin numerador: 1

Preguntas frecuentes

PreguntaRespuesta
¿Se puede cambiar un CMMF Code ya asignado?Las acciones no lo cambian nunca. Si hay que corregirlo, se escribe a mano en el campo. También se puede borrar el CMMF Code (dejarlo en blanco) y volver a asignarlo desde la ficha o la lista: se le dará un código nuevo, el siguiente del numerador de su tipo. El código anterior no se reutiliza.
El error dice que falta CMMF Type, pero lo he seleccionado todoAlgún producto seleccionado no tiene tipo. Mostrar la columna CMMF Type en la lista y filtrarla por vacío para encontrarlo.
"CMMF Type sin numerador" sale mayor que 0Ese tipo no está dado de alta en la lista de valores o no tiene Nº Serie CMMF. Completar el paso 2 y repetir. Los que ya se asignaron se saltarán.
¿Puedo crear un tipo nuevo?Sí: añadir una línea en la lista de valores (paso 2) con su numerador (paso 1).
